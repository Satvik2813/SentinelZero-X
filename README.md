# SentinelZero-X

SentinelZero-X is an agentic automation and simulated testing toolkit, designed for evaluating models and strategies within the SentinelZero simulator platform.

## Structure
- `starter-kit/`: Core agent code for SentinelZero.
- `hardening/`: Scripts and tools for regression analysis and semantics.
- `query.py`: Scripts for querying the mock DB.

## Getting Started

Check out the `starter-kit` and `hardening` directories for further instructions.
